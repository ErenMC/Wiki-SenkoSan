# 🧊 Заморозка ИИ Жителей

* Команды:  \
  /noai <радиус> — Отключает интеллект жителям (они перестают двигаться, обновлять карточки торгов, при повышении уровня).  \
  /ai <радиус> — Включает интеллект обратно.  <br>
* Товары обновляются автоматически через 2 дня, только если на товаре крестик.  <br>
* Жители могут повышать уровень при торговле даже без ИИ.
