# 📃 3. Приват

{% hint style="info" %}
Так как на сервере нет плагинов для приватов, то игроки могут сами обозначать свою территорию.
{% endhint %}

{% hint style="danger" %}
После развития рп-составляющей, администрация не влезает в разборки по приватам.
{% endhint %}

3\. Приват\
\
3.0 - Приват должен быть сделан с использованием выделяющих блоков: ковры ярких цветов, светящиеся блоки (не факел или фонарь).<br>

3.1 - Приватится только та территория, которая используется.

Как пример:

<div data-with-frame="true"><figure><img src="../../../.gitbook/assets/unknown (2).jpg" alt=""><figcaption></figcaption></figure></div>

3.2 - Рядом с домом/порталом должна быть кафедра с информацией, чья это территория и кто там проживает.\
\
3.3. - Проживающий на территории имеет право устанавливать свои правила, не нарушая при этом правила основной территории, на которой размещено здание.

3.4. - Игрок не имеет права приватизировать территорию внутри привата.

3.5. Между чужими приватами должен быть промежуток в 35 блоков.\
3.5.1. Приваты могут располагаться очень близко, если обе стороны это согласовали и не имеют возражений.

3.5.2 - В случае если имеются возражения, обратитесь к администрации/модерации сервера.

3.6 - Если ваша территория расположена под землёй, то вы можете поставить табличку + кафедру.

3.6.1 - На табличке напишите, кому принадлежит территория.

3.6.2 - Желательно на земле так же обозначить территорию (Пункт 3.0)

3.7 - Разрешено приватить только ту территорию, которая используется

3.8 - Правила привата для структур и данжей:

| Разрешено          | <mark style="color:orange;">Частичный приват</mark> | <mark style="color:red;">Запрещено</mark> |
| ------------------ | --------------------------------------------------- | ----------------------------------------- |
| Деревни            | Крепость нижнего мира                               | Город вардена                             |
| Подводная крепость | Бастионы                                            | Медный дворец/Камеры испытаний            |
| Колодец            | Цитадель/Портал энд                                 | Лесной особняк                            |
| Аванпост           |                                                     |                                           |
|                    |                                                     |                                           |

3.8.1 - При частичном привате вы имеете право заприватить саму структуру для собственного использования (пример, фермы). Проход к сундукам в структуре должен быть открытым для других игроков (проще говоря, сундуки приватить в структуре нельзя!!!)\
\
3.8.2 - В частичном привате нельзя полностью разрушать структуру и сундуки. Должна оставаться платформа на которой можно ходить<br>
